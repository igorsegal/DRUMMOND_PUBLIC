# Contributing

Contributions and research criticism are welcome.

## Safety boundary

- Do not submit broker/vendor historical market-data files.
- Do not submit credentials, tokens, account identifiers, private keys, or secrets.
- Do not commit generated BIN/HST/FXT/HCC/ZIP datasets.
- Pull requests must not weaken causal/no-look-ahead research contracts without explicitly documenting the change.
- Research results should distinguish hypothesis generation from validation.

## Pull requests

External pull requests do not automatically run the private-data D27 workflow. Maintainers review code before any merge or privileged research run.
